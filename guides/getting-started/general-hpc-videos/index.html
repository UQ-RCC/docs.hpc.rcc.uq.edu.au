Basic Linux/Unix commands

Section titled “Basic Linux/Unix commands”

These videos follow the content of Software Carpentry – The Unix Shell (https://swcarpentry.github.io/shell-novice/). Sessions 1, 2 and 3 provide instructions on the Linux/Unix commands needed (at the bare minimum level) for new users of HPC. The videos give an overview of the basic command. Further details and exercises with solutions can be found on the Software Carpentry – The Unix Shell page.

Where am I?, list what is here, manual for commands

Section titled “Where am I?, list what is here, manual for commands”

This video gives an overview of how to find out where a user is in the filesystem (pwd), list of what is there (ls) and how to find out all the options/flags that can be used with a particular command (man).

pwd, ls, man

pwd - print name of current/working directory
ls - list directory contents
ls [OPTION] [PATH-TO-FILE or PATH-TO-DIRECTORY]
man - an interface to the system reference manuals
man [COMMAND]

Moving around the file system (folders)

Section titled “Moving around the file system (folders)”

Overview of how to move around the file system, change into other directories (cd).

cd

cd – change the current directory
cd [PATH-TO-DIRECTORY]
cd on its own will change into the user’s home directory
cd .. will go one directory up from the current one

Creating directories (folders) and files

Section titled “Creating directories (folders) and files”

Overview of how to create new directories and files. New files are created with the editor nano.

mkdir, nano

mkdir - creates a new directory.
mkdir [PATH-TO-DIRECTORY]
nano - Nano’s ANOther editor
nano [PATH-TO-FILE]

vi editor

Section titled “vi editor”

Overview of how to use the vi editor to edit files.

vi
Further commands within vi can be found here: http://www.atmos.albany.edu/daes/atmclasses/atm350/vi_cheat_sheet.pdf

vi – powerful text editor
vi [PATH-TO-FILE]

i – insert mode
Esc – leave insert mode
:w – write/save file
:q – exit file
:wq – save and then exit file
:q! - override any changes and exit file without saving

File viewers

Section titled “File viewers”

Overview of file viewers available.

cat, more, less

cat – prints the whole file content to screen.
cat [PATH-TO-FILE]
more – prints a file to screen page by page, press space bar for next page.
more [PATH-TO-FILE]
less – prints a file to screen page by page. Scrollable, use page-down and page-up or arrow keys to navigate through the file. Press q to quit.
less - [PATH-TO-FILE]

Copying, moving (renaming) files and directories

Section titled “Copying, moving (renaming) files and directories”

Overview of how to copy and move files and directories.

cp, mv

cp – copies a file or directory
cp [PATH-TO-OLD-FILE] [PATH-TO-NEW-FILE]
cp –r [PATH-TO-OLD-DIRECTOR] [PATH-TO-NEW-DIRECTORY]
mv – moves (renames) a file or directory
mv [PATH-TO-OLD-FILE] [PATH-TO-NEW-FILE]
mv –r [PATH-TO-OLD-DIRECTOR] [PATH-TO-NEW-DIRECTORY]

Removing files and directories

Section titled “Removing files and directories”

Overview of how to remove files and directories.

IMPORTANT On Linux/Unix removing is for ever. There is no recovery.
rm

rm – removes (deletes) a file or directory. This is not reversible. Once deleted it is gone and cannot be recovered.
rm [PATH-TO-FILE]
rm –r [PATH-TO-DIRECTORY]
