Example Slurm Scripts

Simple script for CUDA GPUs.

Section titled “Simple script for CUDA GPUs.”

For full A100 change to
#SBATCH --gres=gpu:a100:1

For H100 change to
#SBATCH --gres=gpu:h100:1

For L40s change to
#SBATCH --gres=gpu:l40s:1

Simple script for AMD ROCM GPUs.

Section titled “Simple script for AMD ROCM GPUs.”

Nodes bun001, bun002, bun070, bun144, bun145, and bun159 - bun161. These are AMD GPUs. You most likely will need to compile your own code or use a container to run on these.

For Mi300x change to
#SBATCH --gres=gpu:mi300x:1
With --qos=gpu you can ask for up to 4
With --qos=sdf you can ask for all 8

For Mi355x change to
#SBATCH --gres=gpu:mi355x:1
With --qos=gpu you can ask for up to 4
With --qos=sdf you can ask for all 8
